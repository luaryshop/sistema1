# CREDENCIAIS DOS MARKETPLACES (Opcional - preencha só o(s) que for usar)

# URL de callback usada por TODOS os marketplaces abaixo (mesma rota no servidor).
# Precisa apontar exatamente para a página de Marketplaces do painel (não é uma

# MESMA URL no painel de desenvolvedor de cada marketplace (Mercado Livre, Shopee etc).
